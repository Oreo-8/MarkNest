# MarkNest 隐私政策 / Privacy Policy

生效日期 / Effective date: 2026-08-24

## 中文

MarkNest 是一款在浏览器本地运行的 Markdown 阅读、编辑与 AI 对话收录扩展。

### MarkNest 处理的数据

- 当用户打开本地 Markdown 文件时，MarkNest 会读取该文件内容，以便在浏览器中预览和编辑。
- 仅当用户主动点击“收录对话”时，MarkNest 才会读取当前受支持 AI 网站标签页中的对话文本、页面标题和来源网址，并将其转换为 Markdown。
- MarkNest 会在浏览器本地存储界面设置、编辑会话和待打开的收录结果。

### 数据用途与共享

上述数据仅用于提供 Markdown 阅读、编辑、保存、会话恢复和 AI 对话导出功能。MarkNest 不会把本地文件、AI 对话内容、浏览历史或设置发送给开发者或任何第三方服务器，不出售用户数据，也不将用户数据用于广告、画像或信用评估。

用户主动选择保存位置时，生成的 Markdown 文件会保存到用户设备。浏览器的扩展存储可能按浏览器自身规则保留在用户设备上；卸载扩展或清除扩展数据后，这些数据会被删除。

### 权限说明

MarkNest 使用浏览器存储权限保存本地设置与编辑会话；使用活动标签页和脚本权限，在用户主动操作后读取当前受支持 AI 对话页；使用下载权限让用户选择本地 Markdown 保存位置；使用本地文件网址访问权限预览和编辑用户主动打开的 Markdown 文件。对支持的 AI 网站的访问仅用于识别当前页面并响应用户主动发起的“收录对话”操作。

### 联系方式与变更

如对本政策有疑问，请通过 MarkNest 项目仓库的 Issue 页面联系开发者。本政策如有更新，将在本页面公布并更新生效日期。

## English

MarkNest is a browser extension that reads and edits Markdown files locally and lets a user export a supported AI conversation to Markdown.

### Data processed by MarkNest

- When a user opens a local Markdown file, MarkNest reads the file content so it can render and edit the file in the browser.
- Only after the user selects **Capture conversation**, MarkNest reads the conversation text, page title, and source URL from the active tab of a supported AI website and converts that content to Markdown.
- MarkNest stores interface settings, editing sessions, and pending capture results in browser-local extension storage.

### Use and sharing of data

This data is used only to provide Markdown viewing, editing, saving, session recovery, and conversation export. MarkNest does not send local files, conversation content, browsing history, or settings to the developer or any third-party server. MarkNest does not sell user data or use it for advertising, profiling, or credit decisions.

Generated Markdown files are saved on the user's device at a location selected by the user. Browser-local extension data remains subject to the browser's storage behavior and is removed when the extension is uninstalled or its data is cleared.

### Permission usage

MarkNest uses storage permission for local settings and editing sessions; active-tab and scripting permissions to read a supported AI conversation after an explicit user action; downloads permission so the user can choose a local destination for generated Markdown; and file-URL access to render and edit Markdown files that the user opens. Access to supported AI websites is used only to recognize the current page and respond to a user-initiated capture action.

### Contact and updates

Questions about this policy can be submitted through the Issues page of the MarkNest project repository. Updates to this policy will be published on this page with a revised effective date.
